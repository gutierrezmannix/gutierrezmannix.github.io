# Lemma tables

`es`, `en`, `pt` and `fr` lemma lookup tables from **spacy-lookups-data 1.0.5**
(Explosion AI, MIT License, https://github.com/explosion/spacy-lookups-data).
They are embedded in `index.html` as gzip assets and decompressed only when
“Word forms → Lemmas” is chosen in the Text analysis tab.
